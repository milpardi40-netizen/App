Positions 1–150 are the Pre-A1 target; the whole 449-family core is the A1 target (the A1 ceiling allows 500). It is the target for pre and A1 only, and the file names those bands, so a higher band never silently inherits a beginner list.
Bands above A1 are measured against the corpus list instead: a beginner core says nothing about B1.
