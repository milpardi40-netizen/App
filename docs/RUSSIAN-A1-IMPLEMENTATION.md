# اجرای محتوای روسی A1

تاریخ: ۲۰۲۶-۱۱-۲۶ · شاخه: `arena/a1254942-app` · مبنای کنترل محتوا: `acdbd68`

## وضعیت پس از بازبینی و اصلاح

پنج ایرادِ اتصال محتوا به تجربهٔ واقعی درس اصلاح شدند؛ جزئیات و حدود آزمون در [گزارش بازبینی و اصلاح](RUSSIAN-A1-IMPLEMENTATION-REVIEW.md) آمده است. اتاق فعلی ابتدا مکالمهٔ پیوسته و سپس مرور تمام جمله‌های آموزشی را اجرا می‌کند. تست کامپوننت واقعی برای هر دو شروع‌کننده، پوشش **۴۶۴ از ۴۶۴ جمله** را تأیید کرد (۵۸ اجرای کامل). نوشتن اختصاصی، برچسب A1، تاریخچهٔ جداشده و متن‌های خودبسنده نیز آزموده شدند. صفحه یا مرحلهٔ تازه و schema ذخیرهٔ تازه اضافه نشده است؛ اصلاح محدودِ اتصال و برچسب‌های لازم در همان صفحه‌ها انجام شد.

## انجام‌شده

- هر ۲۹ درس در ترتیب مصوبِ ۹ بخش وارد بانک واقعی برنامه شد؛ فقط سند طراحی نیست.
- توضیح فارسی، متن روسی، راهنمای تلفظ فارسی، الگو، واژگان، گفت‌وگو و سؤال‌های هر درس هماهنگ شدند. مرور پیش‌نیاز و نوشتن اختیاری در دفتر در همان متن آموزشی موجود قرار دارد؛ صفحه یا مرحلهٔ تازه‌ای اضافه نشده است.
- ۵۸ تمرین اختیاری شنیدن/خواندن از صورت‌های آموزش‌داده‌شده بازترکیب شده‌اند. این‌ها تولید آزاد یا آزمون رسمی سطح نیستند.
- منبع اتاق مکالمه، کارت‌های جنسیت و نشانی نمونه‌های کارگاه فعل برای A1 با متن جدید هماهنگ شد. واژه‌نامهٔ عمومی فعل و نشانی‌های غیر A1 تغییر نکردند.
- تعداد درس‌ها، شناسهٔ تمام جمله‌ها، ظرفیت فعلی هر درس و ده مرحلهٔ موجود حفظ شده است. ۱۶ جایگاه موجود هر درس حفظ شده‌اند تا نشانگر جملهٔ ذخیره‌شده معتبر بماند؛ این عدد معیار آموزشی عمومی یا الزام برای تألیف‌های آینده نیست.
- محتوای واقعی Pre-A1 و A2 تا C1 روسی و تمام محتوای شش زبان دیگر با هشِ نسخهٔ پیش از تغییر مقایسه شد: یکسان‌اند.

## ذخیره و پیشرفت

کلیدهای ذخیره و schema عوض نشده‌اند. تکمیل درس، شناسهٔ درس جاری، مرحله، شمارهٔ جمله و زمان ثبت‌شده حفظ می‌شوند. بازچینی، مقصد صریح «ادامه» را عوض نمی‌کند؛ درسِ بعدیِ بازدیدنشده طبق ترتیب جدید انتخاب می‌شود.

فقط پاسخ‌های سؤال‌های قدیمی A1 برای تلاش جدید استفاده نمی‌شوند، چون معنی سؤال‌ها عوض شده است. نتایج قدیمی گفتاری/سنجش نیز به جمله‌های بازنویسی‌شده نسبت داده نمی‌شوند؛ رکوردهای خام تاریخی پاک یا هنگام خواندن بازنویسی نمی‌شوند. پاسخ و نمرهٔ تلاش جدید با revision مخصوص A1 ذخیره می‌شود. محتوای غیر A1 revision سابق را نگه می‌دارد.

## بازتولید و آزمون

ورودی ماندگار تألیف: `docs/russian-a1-architecture/runtime/{lessons,skills,verb-links}.json`.

```sh
python docs/russian-a1-architecture/runtime/generate.py
npm run typecheck
npm run validate:russian-a1
```

آزمون جدید ۲۹ درس، گروه‌بندی، ۵۸ متن فهم، صورت‌های دقیقِ ازپیش‌آموزش‌داده‌شده، نقش‌ها، هر دو منبع اتاق، کارت‌ها، ارجاع فعل‌ها، حفظ محتوای غیرهدف و ادامهٔ مبتنی بر شناسه را کنترل می‌کند. ۱۷۴ حالتِ خواندن جلسهٔ قدیمی در شاخه‌های ذخیرهٔ web/android و ذخیرهٔ تلاش جدید آزموده شد؛ شبیه‌سازی ذخیره است، نه آزمایش روی تلفن واقعی.

موارد موفق در این اجرا:

- TypeScript (`tsc --noEmit`).
- `verify-russian-a1`، `verify-russian-course`، `verify-russian-pre-a1-masculine`، `verify-russian-practical`، `verify-russian-prea1-ui-dedup`، `verify-russian-recycling`.
- `verify-lesson-gender`، `verify-lesson-assessment`، `verify-level-resume`.
- `verify-six-prea1-practical`، `verify-prea1-balance`.
- `verify-dialogue-room`، `verify-russian-speech-flow`.
- `verify-english-backup`، `verify-personal-sync`، `check-russian-sentences`.
- `docs/russian-a1-architecture/validate.cjs` و `git diff --check`.

دو آزمون قدیمی نیز اجرا شدند و شکست خوردند. اجرای جداگانهٔ **همان آزمون‌ها روی آرشیو دست‌نخوردهٔ HEAD، پیش از تغییر این نوبت** همان خطاها را نشان داد:

- `verify-russian-redesign.cjs:30`: انتظار قدیمیِ ۸ جمله برای درس اول Pre-A1، در حالی که نسخهٔ مبنا هم ۱۲ جمله دارد.
- `verify-russian-studio.cjs:120`: انتظار نمونه برای تک‌تک فعل‌ها در همهٔ سطح‌ها (`samples.length > 0`).

این دو خطای پیشین در این کار اصلاح یا دور زده نشدند. موفقیت آزمون‌های بالا به معنی تأیید مستقلِ زبان‌شناسی، پوشش کامل واژگان رسمی، تسلط یادگیرنده یا گواهی CEFR نیست. تست تلفن واقعی و انتشار انجام نشده است.

## انتشار

هیچ APK، تغییر شمارهٔ نسخه یا انتشار تازه‌ای ساخته نشده است. طبق درخواست کاربر، ابتدا باید جزئیات ایرادهای نسخهٔ ۱۷۹ دریافت شود؛ سپس رفع ایراد، بررسی و ساخت APK جداگانه انجام می‌شود.
